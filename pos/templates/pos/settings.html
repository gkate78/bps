Backup to Google Sheets

A copy of bills, customers and shop records in your own Google Sheet, one tab each, for viewing from anywhere. PINs and settings are not sent. To restore BPS, use the database backups in ~/bps-data/backups.

Set up (once)
  1. Make a new Google Sheet (e.g. "BPS BACKUP"). Keep it private.
  2. In the sheet: Extensions → Apps Script. Delete what's there and paste the script below (it has your backup password in it). Save.
  3. Deploy → New deployment → type Web app, Execute as Me, Who has access Anyone → Deploy, and allow access when Google asks.
  4. Copy the Web app URL into the box below and save, then press Back up now.
