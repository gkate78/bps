Register and receipt

Business name, address, phone and TIN on shop receipts come from BPS Admin Settings. Staff accounts are managed in BPS too.

Tarpaulin

For tarps printed by another shop. The cost a sq ft is used for the TARPAULIN (SENT OUT) material that Stock's set-up adds (change it there afterwards). Small tarps: a size typed at the register below this many sq ft is suggested at the small price, and costs the small cost. 0 = not used.

Backup to Google Sheets

A copy of bills, customers and shop records in your own Google Sheet, one tab each, for viewing from anywhere. PINs and settings are not sent. To restore BPS, use the database backups in ~/bps-data/backups.

Every backup replaces the tabs, so don't type in them. The PAYMENT REFERENCES tab lists the pending bills (txn date/time, account, biller, bill amount, due date, BPS reference); type the payment reference and channel beside them (e.g. from home). Backups keep what you type there, and Records → Get Sheet References puts them on the bills and marks the rows DONE. Script set up before 11/16/2026? Paste the script below again, then Deploy → Manage deployments → Edit → Version: New version → Deploy (the link stays the same).

Set up (once)
  1. Make a new Google Sheet (e.g. "BPS BACKUP"). Keep it private.
  2. In the sheet: Extensions → Apps Script. Delete what's there and paste the script below (it has your backup password in it). Save.
  3. Deploy → New deployment → type Web app, Execute as Me, Who has access Anyone → Deploy, and allow access when Google asks.
  4. Copy the Web app URL into the box below and save, then press Back up now.
